# Reika's Domain: Egg Hunt

## About The Project
Reika's Domain: Egg Hunt is a simple educational egg hunt game inspired by Capture The Flag (CTF) mechanics. Players search the website for hidden eggs and submit them to win the game. It aims to provide a fun, engaging learning experience through interactive gameplay.

## How to Run Locally
1. Clone the repo: `git clone <repo-url>`
2. Install dependencies: `npm install` (or as per your setup)
3. Run the development server: `npm start`
4. Open `http://localhost:3000` in your browser to play locally
